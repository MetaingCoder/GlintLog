# Hello World

This is the first note on the site. The blog is intentionally simple: Markdown files live in the repository, the browser loads the selected article, and the page renders it on the client.

## Why a static blog?

A static architecture keeps deployment and maintenance small. There is no application server, database, or runtime API involved in serving a post.

```javascript
const message = "Hello, world";
console.log(message);
```

That simplicity is useful when the goal is to spend more time writing and less time maintaining infrastructure.
